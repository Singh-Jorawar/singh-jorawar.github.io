Overview

This project aims to create an automated pipeline that takes a video as input and produces a 3D Gaussian Splat representation of the captured scene.

The system combines multiple computer vision and 3D reconstruction techniques into a single workflow.

Frame Extraction

The input video is first converted into a sequence of images. Frames can then be sampled to reduce redundancy and computational cost.

Object Masking

Unwanted objects are identified and masked using segmentation techniques. SAM2 can be used to propagate masks through the sequence.

Depth Estimation

Depth information is estimated from the extracted frames and used to improve the reconstruction process.

Image Inpainting

Masked regions can be reconstructed using image inpainting models before the images are passed to the reconstruction stage.

COLMAP Reconstruction

COLMAP is used to estimate camera poses and generate the sparse reconstruction required for the subsequent Gaussian Splatting stage.

Gaussian Splatting

The reconstructed scene is then used to train a Gaussian Splat representation, producing a viewable 3D representation of the scene.
